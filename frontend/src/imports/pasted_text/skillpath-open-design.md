Design a modern, clean and developer-focused web application UI called “SkillPath-Open”.

SkillPath-Open is a tool that analyzes a user's GitHub profile and generates a personalized developer learning roadmap based on their existing skills.

The design should look like a modern SaaS dashboard similar to GitHub, Linear, and Vercel.

Use a minimal, modern, developer aesthetic with smooth animations, gradients, soft shadows, rounded cards, and clear typography.

Color style:
Primary color: Indigo / Blue
Accent: Purple gradient
Background: Light neutral or dark developer theme
Use modern UI style similar to developer tools.

Typography:
Modern sans-serif such as Inter or similar.

Add subtle animations for loading states, skill detection, and roadmap progress.
